# Telegram Affiliate Marketing Automation Bot



A 24/7 automated affiliate marketing system built with Python and GitHub Actions.



\## How it works

1\. Monitors multiple Telegram deal channels in real-time

2\. Auto-forwards posts to EarnKaro affiliate bot

3\. Bot converts links to personal affiliate ID

4\. Publishes monetized posts to public Telegram channel automatically



\## Tech Stack

\- Python 3.11

\- Telethon (Telegram MTProto API)

\- Asyncio

\- GitHub Actions (cron scheduling)



\## Features

\- Real-time channel monitoring

\- Duplicate post filtering

\- Rate limiting to prevent account restrictions

\- 24/7 cloud deployment with auto-restart every 5 hours
